# 学生选课管理系统数据库设计报告

---

## 一、概念设计

### 1.1 设计目标

本系统旨在构建一个面向高校的学生选课信息管理平台，实现学生、课程、教师、选课记录的基本管理功能。通过本项目可以学习数据库表的设计与关联、外键约束与参照完整性、级联删除的概念、SQL 语句的编写以及 Python + MySQL 的 CRUD 操作。

### 1.2 实体与属性

本系统包含以下四个核心实体：

#### （1）学生实体（Students）

| 属性 | 说明 | 数据类型 | 约束 |
|------|------|----------|------|
| student_id | 学号 | VARCHAR(20) | PRIMARY KEY |
| name | 姓名 | VARCHAR(50) | NOT NULL |
| gender | 性别 | ENUM('男','女','其他') | NOT NULL |
| age | 年龄 | INT | CHECK (age > 0 AND age < 150) |
| major | 专业 | VARCHAR(100) | - |
| phone | 电话 | VARCHAR(20) | - |
| created_at | 创建时间 | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP |
| updated_at | 更新时间 | TIMESTAMP | ON UPDATE CURRENT_TIMESTAMP |

#### （2）教师实体（Teacher）

| 属性 | 说明 | 数据类型 | 约束 |
|------|------|----------|------|
| teacher_id | 教师编号 | VARCHAR(20) | PRIMARY KEY |
| name | 姓名 | VARCHAR(50) | NOT NULL |
| gender | 性别 | ENUM('男','女','其他') | NOT NULL |
| age | 年龄 | INT | CHECK (age > 0 AND age < 150) |
| title | 职称 | VARCHAR(20) | NOT NULL |
| phone | 电话 | VARCHAR(20) | - |
| created_at | 创建时间 | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP |
| updated_at | 更新时间 | TIMESTAMP | ON UPDATE CURRENT_TIMESTAMP |

#### （3）课程实体（Course）

| 属性 | 说明 | 数据类型 | 约束 |
|------|------|----------|------|
| course_id | 课程号 | VARCHAR(20) | PRIMARY KEY |
| course_name | 课程名 | VARCHAR(100) | NOT NULL |
| teacher_id | 授课教师编号 | VARCHAR(20) | FOREIGN KEY → teacher |
| credit | 学分 | DECIMAL(3,1) | NOT NULL |
| created_at | 创建时间 | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP |

#### （4）选课记录实体（SC）

| 属性 | 说明 | 数据类型 | 约束 |
|------|------|----------|------|
| id | 主键 | INT | PRIMARY KEY, AUTO_INCREMENT |
| student_id | 学号 | VARCHAR(20) | FOREIGN KEY → students |
| course_id | 课程号 | VARCHAR(20) | FOREIGN KEY → course |
| semester | 学期 | VARCHAR(20) | NOT NULL |
| score | 成绩 | DECIMAL(5,2) | NULL (0-100) |
| created_at | 创建时间 | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP |

### 2.2 关系说明

| 关系 | 说明 | 关联方式 |
|------|------|----------|
| 学生 ↔ 选课 | 一对多 | 一个学生可以选修多门课程 |
| 课程 ↔ 选课 | 一对多 | 一门课程可以被多个学生选修 |
| 教师 ↔ 课程 | 一对多 | 一位教师可以教授多门课程 |

### 2.3 业务规则

| 规则 | 实现方式 |
|------|----------|
| 同一学生同一学期不能重复选修同一门课程 | 唯一约束 UNIQUE(student_id, course_id, semester) |
| 成绩范围限制在 0-100 之间 | BEFORE INSERT 触发器检查 |
| 删除学生时自动删除其选课记录 | 外键级联删除 ON DELETE CASCADE |
| 删除课程时检查是否有学生已选修 | 外键约束 ON DELETE RESTRICT |
| 删除教师时自动删除其教授的课程 | 外键级联删除 ON DELETE CASCADE |

## 三、物理设计

### 3.1 建表 SQL

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS student_db DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
USE student_db;

-- 学生表
CREATE TABLE IF NOT EXISTS students (
    student_id VARCHAR(20) PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    gender ENUM('男', '女', '其他') NOT NULL,
    age INT CHECK (age > 0 AND age < 150),
    major VARCHAR(100),
    phone VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 教师表
CREATE TABLE IF NOT EXISTS teacher (
    teacher_id VARCHAR(20) PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    gender ENUM('男', '女', '其他') NOT NULL,
    age INT CHECK (age > 0 AND age < 150),
    title VARCHAR(20) NOT NULL COMMENT '职称：教授/副教授/讲师/助教',
    phone VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 课程表
CREATE TABLE IF NOT EXISTS course (
    course_id VARCHAR(20) PRIMARY KEY,
    course_name VARCHAR(100) NOT NULL,
    teacher_id VARCHAR(20) NOT NULL,
    credit DECIMAL(3,1) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_course_teacher FOREIGN KEY (teacher_id)
        REFERENCES teacher(teacher_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 选课表
CREATE TABLE IF NOT EXISTS sc (
    id INT AUTO_INCREMENT PRIMARY KEY,
    student_id VARCHAR(20) NOT NULL,
    course_id VARCHAR(20) NOT NULL,
    semester VARCHAR(20) NOT NULL,
    score DECIMAL(5,2) DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_sc_student FOREIGN KEY (student_id)
        REFERENCES students(student_id) ON DELETE CASCADE,
    CONSTRAINT fk_sc_course FOREIGN KEY (course_id)
        REFERENCES course(course_id) ON DELETE RESTRICT,
    CONSTRAINT uk_student_course_semester UNIQUE (student_id, course_id, semester)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 3.2 数据库表汇总

| 表名 | 说明 | 主键 | 外键数量 |
|------|------|------|----------|
| students | 学生表 | student_id | 0 |
| teacher | 教师表 | teacher_id | 0 |
| course | 课程表 | course_id | 1 |
| sc | 选课表 | id | 2 |

## 四、完整性约束设计

### 4.1 实体完整性

| 表 | 主键 | 说明 |
|----|------|------|
| students | student_id | 每个学生有唯一的学号标识 |
| teacher | teacher_id | 每位教师有唯一的教师编号 |
| course | course_id | 每门课程有唯一的课程号 |
| sc | id | 每条选课记录有唯一的自增 ID |

### 4.2 参照完整性（外键约束）

| 外键名 | 从表 | 参考表 | 删除策略 | 说明 |
|--------|------|--------|----------|------|
| fk_sc_student | sc | students | CASCADE | 删除学生时自动删除其选课记录 |
| fk_sc_course | sc | course | RESTRICT | 有学生选修时拒绝删除课程 |
| fk_course_teacher | course | teacher | CASCADE | 删除教师时自动删除其教授的课程 |

### 4.3 域完整性（CHECK 约束）

| 表 | 字段 | 约束条件 | 说明 |
|----|------|----------|------|
| students | age | age > 0 AND age < 150 | 年龄必须在 1-149 之间 |
| teacher | age | age > 0 AND age < 150 | 年龄必须在 1-149 之间 |

### 4.4 唯一性约束

| 约束名 | 表 | 字段组合 | 说明 |
|--------|-----|----------|------|
| uk_student_course_semester | sc | (student_id, course_id, semester) | 防止学生同一学期重复选修同一门课程 |

## 五、高级数据库对象

### 5.1 视图（View）

| 视图名 | 作用 |
|--------|------|
| v_student_scores | 将 students、course、sc 三表关联，展示学生成绩明细 |
| v_course_stats | 聚合每门课程的选课人数、平均分、最高分、最低分 |
| v_student_credits | 【课后作业】展示每位学生的总学分和平均成绩 |

### 5.2 触发器（Trigger）

| 触发器名 | 触发时机 | 作用 |
|----------|----------|------|
| trg_before_sc_score_check | BEFORE INSERT | 检查成绩是否在 0~100 之间 |
| trg_before_sc_score_update_check | BEFORE UPDATE | 检查更新成绩是否在 0~100 之间 |
| trg_after_student_delete_log | AFTER DELETE | 学生删除后记录日志 |
| trg_after_student_major_change_log | AFTER UPDATE | 【课后作业】专业变更记录日志 |

### 5.3 存储过程（Stored Procedure）

| 过程名 | 功能 |
|--------|------|
| sp_student_rank | 输入学号，输出该学生在全部学生中的平均成绩排名 |
| sp_course_pass_rate | 输入课程号，输出该课程的及格率 |
| sp_score_bonus | 【课后作业】为指定课程的所有学生成绩统一加分 |

### 5.4 函数（Function）

| 函数名 | 功能 |
|--------|------|
| fn_grade_level(score) | 根据成绩返回等级：优/良/中/及格/不及格/未录入 |
| fn_gpa(score) | 【课后作业】将百分制成绩转换为 4.0 制 GPA |

## 十、总结

本系统通过学生、课程、教师、选课四张表的设计，完整展示了数据库设计的基本要素：

1. **实体完整性**：通过主键约束确保每条记录的唯一性
2. **参照完整性**：通过外键约束维护表与表之间的关联关系
3. **域完整性**：通过 CHECK 约束限制字段取值范围
4. **业务规则**：通过触发器、唯一约束等实现复杂的业务逻辑

系统设计遵循了教学演示的简洁原则，便于学生理解和实践数据库设计的各个环节。
