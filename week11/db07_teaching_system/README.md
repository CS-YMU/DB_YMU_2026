# DB07 关系数据库规范化设计 — 交互式教学系统

涵盖《数据库概论》第 7 讲全部内容（课件 7.1 ~ 7.6），包含课程讲解、交互式算法演示、教学案例库和随堂练习。

## 环境准备

### 1. 创建 Conda 虚拟环境

```bash
conda create -n DB07 python=3.12 -y
conda activate DB07
```

### 2. 安装依赖

```bash
cd week11/db07_teaching_system
pip install -r requirements.txt
```

## 初始化数据库（可选）

系统内置了 75 道练习题和 10 个教学案例的备用数据，**不连数据库也能完整使用**。

如果希望启用学生作答记录功能，先确保 MySQL 已启动，再运行：

```bash
python init_db.py
```

脚本会连接 `config.py` 中配置的 MySQL，自动建库建表并写入数据。可通过环境变量覆盖数据库配置：

```bash
export DB_HOST=localhost
export DB_USER=你的用户名
export DB_PASSWORD=你的密码
export DB_DATABASE=DB07
```

## 启动系统

```bash
python app.py
```

浏览器打开：**http://127.0.0.1:8007**

按 `Ctrl+C` 停止服务。

### 五个主题

| 主题 | 课件对应 | 核心内容 |
|------|---------|---------|
| 为什么要规范化 | 7.1 | 数据冗余、三种操作异常、"一事一地"原则 |
| 函数依赖与推理 | 7.2.1-7.2.4 | FD 定义、Armstrong 公理、实用推理规则 |
| 闭包、候选键与最小依赖集 | 7.2.5-7.2.7 | X⁺ 算法、候选键求解、三步法求最小覆盖 |
| 模式分解 | 7.3 | 无损连接、保持依赖、Chase 过程算法 |
| 范式：1NF 到 5NF | 7.4-7.6 | 逐级规范化、BCNF/4NF/5NF、工程权衡 |

### 六个交互工具

每个工具在右侧面板中，点击即可切换：

| 工具 | 功能 | 课堂用法 |
|------|------|---------|
| **练习** | 75 道随堂题（每主题 15 题） | 讲完一个主题后布置练习 |
| **闭包** | 自定义 FD 计算 X⁺，分步展示 | 演示闭包算法的迭代过程 |
| **候选键** | 输入属性和 FD，找所有候选键 | 验证学生手动求解结果 |
| **最小覆盖** | 三步骤演示最小依赖集计算 | 讲解 Fmin 的标准算法 |
| **范式检查** | 输入模式，判定 1NF~BCNF，指出违规 | 即时验证任何关系模式的范式 |
| **Chase** | 可视化 Chase 过程，判断无损分解 | 动画演示表格修改过程 |

每个工具都内置了**预设示例**，一键加载，方便课堂快速演示。

### 教学案例库

点击左侧「教学案例库（10个）」按钮，可浏览全部案例：

1. 学生选课表 — 异常问题演示
2. 学生-课程-教师综合表 — FD 识别与推理
3. 物流订单系统 — 综合范式判断与 3NF 分解
4. 在线考试系统 — 3NF 分解与插入异常避免
5. 课程-学生-先修课 — BCNF 不够，需要 4NF
6. 教师工资表 — 传递依赖与 3NF
7. 供应商-零件-项目 — 连接依赖与 5NF
8. 闭包与候选键计算 — 分步演示
9. 最小依赖集计算 — 三步法演示
10. 无损 vs 有损分解 — Chase 过程对比

每个案例可一键加载到「范式检查」工具中。

### 教师模式

点击 Topbar 右侧的「讲」按钮，课程面板中会显示**教师提示**（含教学建议、讲解重点和易错点提醒）。

### 课堂进度

左侧边栏底部自动跟踪已浏览的主题数量，进度保存在浏览器 localStorage 中。

## 推荐教学流程（90 分钟）

| 阶段 | 时间 | 操作 |
|------|------|------|
| 导入 | 5 min | 打开案例 1，展示三种异常，引出问题 |
| FD 理论 | 20 min | 切换到主题 2，用闭包工具演示 A⁺ 计算 |
| 候选键与最小覆盖 | 15 min | 主题 3，候选键和最小覆盖工具分步演示 |
| 练习巩固 | 5 min | 前三个主题各做 3-5 道随堂练习 |
| 模式分解 | 20 min | 主题 4，Chase 工具演示无损判定 |
| 范式体系 | 20 min | 主题 5，范式检查工具逐个验证案例 |
| 总结 | 5 min | 打开案例 5 和 7，展示 4NF/5NF 高级概念 |
