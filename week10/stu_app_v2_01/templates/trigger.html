触发器（Trigger）

触发器是实现数据库完整性约束自动执行的 SQL 程序。当特定事件（INSERT、UPDATE、DELETE）发生时，数据库自动触发执行预定义的代码逻辑。

触发器的核心概念

要素说明
触发时机 BEFORE（操作前）/ AFTER（操作后）
触发事件 INSERT、UPDATE、DELETE
作用范围 FOR EACH ROW（行级）/ FOR EACH STATEMENT（语句级）
特殊变量 NEW — 新数据（INSERT/UPDATE）；OLD — 旧数据（UPDATE/DELETE）

本项目中的触发器：trg_grade_check

功能说明

在 student_course 表执行 INSERT 操作前，自动检查成绩是否在 0-100 范围内。如果成绩不合法，阻止插入并抛出错误。

源码

CREATE TRIGGER trg_grade_check
BEFORE INSERT ON student_course
FOR EACH ROW
BEGIN
    IF NEW.Grade IS NOT NULL AND (NEW.Grade < 0 OR NEW.Grade > 100) THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = '成绩必须在 0-100 之间';
    END IF;
END

关键点解析

  • BEFORE INSERT — 在数据真正插入表之前执行检查
  • FOR EACH ROW — 每插入一行触发一次
  • NEW.Grade — 访问即将插入的新行的 Grade 字段值
  • SIGNAL SQLSTATE '45000' — 抛出用户自定义错误，阻止不合法操作

触发器 vs 应用程序校验

对比维度应用程序层校验数据库触发器校验
可靠性 绕过应用直接操作数据库时失效 无论通过什么方式操作数据，都会强制执行
性能 数据已传输到应用层才发现错误 在数据库层即时拦截，减少网络往返
维护 规则分散在各应用代码中 规则集中存储在数据库中，一处修改全局生效
灵活性 可以访问外部服务，逻辑更灵活 只能在数据库内部操作，受限于SQL能力

触发器的适用场景

  • 数据完整性约束：如成绩范围检查、日期合理性检查
  • 审计日志：自动记录谁在什么时间修改了什么数据
  • 级联更新：主表数据变更时自动同步相关表
  • 派生字段计算：自动计算并存储冗余字段（如总数量、平均值）
注意：触发器虽然强大，但过度使用会导致数据库逻辑隐蔽、调试困难。建议在数据完整性约束和审计场景使用，复杂业务逻辑仍应放在应用层或存储过程中。
