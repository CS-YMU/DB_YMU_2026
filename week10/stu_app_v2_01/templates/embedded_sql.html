嵌入式 SQL（Embedded SQL）

将 SQL 语句嵌入到宿主语言（如 Python）的代码中，实现应用程序对数据库的访问。

核心概念对照

PPT 概念通用说明本项目中的对应实现
宿主语言 嵌入 SQL 的编程语言（如 Python） Python — Flask 路由函数中编写 SQL 访问代码
SQL 通信区 (SQLCA) 向主语言传递 SQL 语句的执行状态信息，使主语言能据此控制程序流程 cursor 对象 — 承载 SQL 执行状态（成功/失败、影响行数等）
cursor.rowcount、cursor.fetchone() 等方法提供状态反馈
共享变量 主语言向 SQL 语句提供参数；将 SQL 查询结果交主语言进一步处理 参数化查询的 %s 占位符 — Python 变量值通过占位符传入 SQL
cursor.execute("SELECT ... WHERE ID = %s", (student_id,))
游标 (Cursor) 存放 SQL 查询结果集的缓冲区，解决集合操作 SQL 与过程语言处理的不匹配 cursor 结果集 — cursor.fetchall() 逐行获取查询结果
等价于 EXEC SQL FETCH SX INTO ...

代码示例：本项目中的嵌入式 SQL

示例1：带参数的 SELECT（共享变量 + 通信区 + 游标）

来自 database.py 的 get_student_by_id() 方法：

# ===== Python 宿主语言代码 =====
def get_student_by_id(self, student_id):
    # SQL 语句嵌入在 Python 代码中（嵌入式 SQL）
    # %s 是占位符，对应嵌入式 SQL 的 ? 占位符
    # student_id 是共享变量，向 SQL 传递数据
    sql = "SELECT ID, Name, Sex, Age, Dept FROM student WHERE ID = %s"

    # cursor 同时扮演：
    # 1. SQL 通信区 — 执行状态（成功/失败）
    # 2. 游标 — 存放查询结果集
    self.cursor.execute(sql, (student_id,))

    # FETCH INTO — 从游标读取一行数据到共享变量(Python变量)
    return self.cursor.fetchone()

示例2：C 程序中的嵌入式 SQL（PPT 示例对比）

// 定义共享变量
EXEC SQL BEGIN DECLARE SECTION;
    char  S_DeptName[64];
    char  S_StdID[64];
    char  S_StdName[64];
    int   S_StdAge;
EXEC SQL END DECLARE SECTION;

// 定义 SQL 通信区
EXEC SQL INCLUDE sqlca;

// 定义游标 SX
EXEC SQL DECLARE SX CURSOR FOR
    SELECT ID, Name, Sex, Age
    FROM Student
    WHERE Dept = :S_DeptName;   // :S_DeptName 是共享变量

// 打开游标，逐条 FETCH
EXEC SQL OPEN SX;
while(1) {
    EXEC SQL FETCH SX INTO :S_SID, :S_SName, :S_SSex, :S_SAge;
    if (sqlca.sqlcode != 0) break;  // SQL 通信区判断成功与否
    // 处理数据...
}
EXEC SQL CLOSE SX;

示例3：动态嵌入式 SQL

Python 中的动态 SQL 组装（对应 PPT 的 EXECUTE IMMEDIATE）：

# 运行时根据用户输入动态组装 SQL 语句
def search_students(self, keyword, dept=None):
    sql = "SELECT * FROM student WHERE Name LIKE %s"
    params = [f"%{keyword}%"]

    if dept:  # 运行时动态追加条件
        sql += " AND Dept = %s"
        params.append(dept)

    # 等价于 PPT 中的：
    # EXEC SQL PREPARE stmt FROM :sqlstr;
    # EXEC SQL EXECUTE stmt USING :param1, :param2;
    self.cursor.execute(sql, tuple(params))
    return self.cursor.fetchall()

为什么需要游标？

SQL 是集合操作语言，一条 SELECT 返回的是一个集合（多行数据）。

宿主语言是过程操作语言（C、Python 等），一次只能处理一条记录。

游标作为桥梁，将集合结果逐条传递给宿主语言处理，解决了这种"阻抗不匹配"问题。

在现代编程中，cursor.fetchone() / cursor.fetchall() 就是游标的实际体现。
